# NetworkAR Final
Kotlin + Jetpack Compose Android project with Wi-Fi/4G/5G signal monitoring, speed-test metrics, Wi-Fi-vs-mobile comparison, Room history and an ARCore heatmap foundation.

The GitHub Actions workflow installs Gradle directly, avoiding the missing-wrapper problem from the earlier prototype.

Note: upload speed is left at 0 until a proper upload test endpoint is configured. ARCore camera/pose integration is a production follow-up; the heatmap engine and project foundation are included.
